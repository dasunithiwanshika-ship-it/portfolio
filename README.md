## 🌐 Deployment (GitHub Pages)

This website is built with zero build dependencies (Vanilla HTML5, CSS3, JavaScript) and is 100% compatible with GitHub Pages:

1. Push this repository to GitHub:
   ```bash
   git add .
   git commit -m "Update portfolio with verified Sharentals repos and separated case studies"
   git push origin main
   ```
2. In GitHub repository settings:
   - Go to **Settings** → **Pages**
   - Under **Build and deployment** > **Source**, select **Deploy from a branch**
   - Select branch: `main` and folder `/ (root)`
   - Click **Save**
